# DAS Lab AI Office

조직도에서 직원의 기억·현재 업무·실행 상태·결과를 확인하고, 자연어 업무 지시와 개입을 기록하는 로컬 조직 운영 엔진입니다. 대표 → 전용 비서 → DAS Lab PM → R&D·기획마케팅·영업지원의 책임 구조를 사용합니다.

## 열기

```powershell
python server.py
```

[조직 오피스](http://127.0.0.1:8765/)에서 직원을 선택하거나 비서에게 업무를 맡기세요. 등록된 역할·기억과 지시를 실행 문맥에 포함하고, 일시정지·재개·방향 수정·담당 변경을 원장에 남깁니다. 폼에 목표·기준·우선순위를 따로 작성할 필요는 없습니다.

음성은 선택 기능입니다. **음성 입력**을 누른 때에만 기기에서 인식하고, 확인한 텍스트를 조직 화면으로 가져옵니다. 마이크는 기본적으로 꺼져 있습니다. 모든 업무 제어는 UI로 가능합니다. [음성 설정·한계](docs/VOICE.md)

## 현재 구현과 한계

- 직원·기억·배정·실행 시도·개입·이벤트를 SQLite에 영속 저장합니다. 실행 중 상태는 SSE로 전달합니다.
- 공식 Codex CLI의 기존 ChatGPT 구독을 사용합니다. 동시 1개이며 `config/office.json`의 일일 실행 수·시간·재시도 한도를 따릅니다. API 과금 자동 전환은 없습니다.
- 초기 비서 접수와 담당 배정은 코드 규칙입니다. 각 실제 작업은 해당 직원의 문맥으로 Codex가 수행합니다. 여러 LLM 관리자 간 자율 협상·자동 임시 직원 생성·정기 업무 실행은 아직 없습니다.
- 기본 실행 능력은 제공 문맥의 분석·문서·코드 제안입니다. PM·R&D는 현재 조직 UI의 별도 작업본을 실제 수정하고 정적 검사 뒤 로컬 미리보기를 만들 수 있습니다. 일반 저장소 개발·외부 조회·발송·공개 배포는 연결하지 않았습니다.
- 결과 보고·AI 자기평가·형식 검증·실제 사업 성과를 구분합니다. 형식 검증 통과만으로 검증된 달성 건수를 올리지 않습니다.
- 일시정지 후 재개는 기록을 이어받는 새 시도입니다. 서버가 중단되면 미완료 업무를 자동 실행하지 않습니다. 다시 열어 재개하세요.

## 데이터

새 조직 데이터는 `data/organization.sqlite3`에 저장합니다. 기존 미션 데이터와 파일은 보존하며 [이전 미션](http://127.0.0.1:8765/legacy)에서 조회할 수 있습니다. 새 서버에서는 이전 실행기 쓰기 경로를 막아 두 실행기가 동시에 구독량을 소모하지 않게 합니다.

서버는 `127.0.0.1`에서만 접속하는 대표 1인용입니다. 여러 PC에서 동기화 중인 같은 SQLite를 동시에 열지 마세요. 별도 저장 위치는 `python server.py --data-dir C:\DASLabOfficeData`로 지정할 수 있습니다.
