남은 운영 전환 작업은 자동 UI 검수 환경, 기존 직원·업무 이력과 정기업무의 중복 없는 이전, 폰 인증 연결, 재시작·복구 검증, 일반 process adapter의 사용량 집계다. 연구·마케팅·영업·투자심사의 실제 성과나 장기간 자율 운영은 이 3역할 시험으로 입증되지 않았다. 사용자가 보류한 휴대폰 음성 시험은 PENDING이다.
