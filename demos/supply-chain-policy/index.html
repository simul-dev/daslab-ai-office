동일 조건의 세 정책 비교

비교 입력 (모두 정수)

P0: 3일 수요 목표 · P1: 기본 목표 + 추가 안전재고 · P2: 기본 목표 유지, 지연이 예고된 기존 발주 일부를 출발 전 긴급 전환. 초기 물리재고는 동일합니다.

정책별 기말 주문 상태 · 2D

완료 / 배송 중 / 예약·피킹 / 미예약 대기 순서입니다. 아래 기존 피킹 모형과 별도 계산입니다.

가정·단위·계산 근거

주문당 1개, 도착 후 2일 이내 배송 완료가 납기 준수입니다. 예약 후 0.25일에 출하, 출하 후 0.5일에 배송합니다. 피킹·배송 용량은 무제한입니다. 매일 시각 0부터 재고위치를 검토해 목표 부족량을 발주합니다.

정규 출발: 발주 +0.5일, 입고: 발주 +2일 + 공통 지연. 시각 2–7일 발주는 3일 지연, 나머지는 별도 시드 난수로 0 또는 1일 지연입니다. 긴급 출발 +0.25일, 입고 +1일. 지연을 발주 시 알고 있다는 합성 가정입니다.

물리재고는 예약분을 포함합니다. 재고위치 = 물리재고 − 예약 + 미입고 발주 − 미예약 대기. 보유비 0.1 CU/(개·일), 정규 운송 1 CU/개, 긴급 운송 4 CU/개, 발주비 2 CU/건. CU는 합성 비용 단위이며 원화가 아닙니다. 운송비는 기간 밖 미입고도 발주 시 부과합니다.

OTIF = 기한 내 배송 완료 / 전체 유입 (미완료 포함, 무수요 0). 평균 소요일은 완료 주문만 집계합니다. 보유비는 예약분을 포함하는 물리재고 시간적분입니다. 수요·지연은 정책 행동과 독립 생성됩니다. 실제 고객 성과·영업 납기 약속·3D·현장 적합성을 입증하지 않습니다.

전체 원시 추적 펼치기 (입력·수요·지연·주문·발주·입고·상태·비용)


기준 시나리오·0 경계 조건 자체 검사입니다. 서버 독립 계산 및 브라우저 검증 결과가 아닙니다.
    

    기존 재고·피킹 모형 (별도 유지 모형)
    주문 도착·피킹·재입고를 사건 단위로 계산하는 합성 데모입니다. 실고객 성과나 검증된 운영 모델을 뜻하지 않습니다.
