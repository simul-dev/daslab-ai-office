입력 시작 버튼을 누른 동안에만 듣습니다. 등록 목소리와 일치하지 않는 말, 겹침·불확실성이 감지된 발화는 폐기합니다. 호출 후 다음 명령도 다시 검사합니다. 짧거나 시끄러운 발화는 본인이라도 거절될 수 있습니다.

학습된 공개 모델을 사용하지만 대표님의 실제 목소리·다른 화자·한국어 짧은 호출 정확도는 아직 측정 전입니다. 녹음 재생·합성 음성을 완전히 차단하는 기능은 없습니다. 음성은 결제·계약·발송·권한 변경의 승인 수단이 아닙니다.

현재는 화면을 켜고 이 페이지를 보고 있을 때만 듣습니다. 다른 탭·화면 잠금 시 중지합니다. Fold4 잠금화면 상시 호출은 지원하지 않으며, 모바일 연결에는 HTTPS와 별도 기기 검증이 필요합니다.
