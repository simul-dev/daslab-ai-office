# 조직 운영 엔진 검증 기록

기준일: 2026-09-29. 이 기록은 조직 운영 엔진과 웹 제어 기능의 검증이다. 이전 v0.4 구축 계획의 전체 단계 완료나 DAS Lab 데모 개선·홍보의 사업 성과를 뜻하지 않는다.

## 검증 범위

`tests/test_organization_http.py`는 임시 데이터 폴더의 실제 SQLite 저장소와 실제 loopback HTTP 서버를 사용한다. 실행 제공자만 주입한 가짜 Worker다. 테스트가 구독 CLI·유료 API·운영 데이터·마이크를 호출하지 않는다.

| 확인 대상 | 확인 방식 |
|---|---|
| 조직과 직원 식별자 | 대표 → 비서 → DAS PM → R&D·마케팅·영업의 실제 조회 응답 |
| 자연어 업무 접수 | 요청 ID 재전송 및 동시에 들어온 동일 요청이 한 미션만 만드는지 검사 |
| 실행 불가 상태 | 미연결 Worker가 실행 기록·진행률·성과를 만들어 내지 않는지 검사 |
| 대표의 개입과 기억 | 추가 지시·담당 변경·직원 기억을 HTTP로 저장하고 엔진 재시작 뒤 재조회 |
| 중지와 담당 변경 | 실행 중 요청에는 중지 중을 표시하고, 이전 Worker의 늦은 완료가 성과로 반영되지 않는지 검사 |
| 직원별 실행 귀속 | 담당 변경 중에도 이전 직원의 실행 상태를 유지하며, 이전 실행 시간을 새 담당자의 성과로 옮기지 않는지 검사 |
| 결과와 검증 구분 | 합성 보고서를 실제 구조 검증기로 확인하고 보고서 수·미검증 기억·목표 달성 여부를 분리 |
| 실시간 상태 전달 | SSE의 최초 상태 및 기억 변경 뒤 실제 revision 갱신 수신 |
| 기존 실행기 격리 | 조직 엔진을 연결한 서버에서 이전 미션 쓰기 경로 차단 |
| 요청 경계 | 외부 Host·Origin, 필수 헤더 누락, 잘못된 JSON·직원·요청 ID 거부 |

## 실행 결과

| 실행 명령 | 결과 |
|---|---|
| `python -m unittest tests.test_organization_http -v` | 12개 통과. 실제 HTTP·SSE, 임시 DB, 가짜 Worker. |
| `python -m unittest tests.test_voice_server tests.test_office tests.test_missions -v` | 54개 중 53개 통과, Windows 심볼릭링크 생성 권한이 필요한 1개 건너뜀. |

담당자를 변경하면 이전 실행 시간과 보고서가 새 직원의 성과로 옮겨지던 문제를 검토에서 발견해 수정했다. 변경 전 Worker가 실제로 멈출 때까지 원래 직원이 작업 중으로 보이는지, 중지 후에도 실행 시간이 원래 직원에게 귀속되는지를 회귀 검사에 포함했다.

브라우저 시험용 `tests/org_fixture_server.py`도 추가했다. 기본 포트는 8766, 실행 대기는 12초이며, 임시 DB에서 가짜 Worker만 사용한다. 최종 보고서는 **합성 보고서·실제 업무 미수행·달성률 미산정**으로 표시한다. 이 fixture의 결과 생성과 구조 검사 흐름은 위 HTTP 시험으로 통과했다. 실제 화면 검증 결과와 실제 구독 실행 결과는 별도로 기록한다.

## 실제 실행과 화면 확인 · 2026-09-29

- 전체 Python 검사: `python -m unittest discover -s tests -q` — 120개 중 119개 통과, Windows 심볼릭링크 권한 검사 1개 건너뜀. 음성 정책 Node 검사 16개 통과. 새 UI JavaScript 문법 검사 통과.
- 별도 테스트 저장소에서 실제 Codex ChatGPT 구독으로 한 문장 연결 확인 업무를 실행했다. 20.9초 뒤 “조직 엔진 연결 정상.” 보고가 돌아왔고 실제 실행 이벤트·보고·직원 기억이 연결됐다. 업무 상태는 독립 검증된 사업 달성이 아닌 보고 준비 상태다. 증거는 로컬 `test-results/org-real-20260929/result-evidence.json`에 보존했다.
- 브라우저와 가짜 Worker로 자연어 업무 접수 → R&D 배정 → 일시 정지 → 추가 지시 저장 → 재개 → 합성 보고를 확인했다. 실행 41초·대표 개입 3회·보고서 1개·검증된 성과 0개로 각각 표시됐다.
- 직원 기억 저장 후 새로고침해 내용이 유지됨을 확인했다. 360px와 1440px 너비에서 가로 넘침이 없고, 확인한 탭의 브라우저 오류·경고 로그는 없었다. 화면 크기 검사를 마친 뒤 임시 viewport 설정을 해제했다.
- 운영 서버의 기존 미션 DB를 백업하고 그대로 보존한 채 새 조직 화면으로 전환했다. 실제 연결 테스트와 합성 작업은 별도 저장소에서 수행해 운영 조직에 가짜 업무·성과를 넣지 않았다.

## 조직 UI 개발 연결 · 2026-09-30

- `python -m unittest discover -s tests -q`: 142개 중 140개 통과, Windows 심볼릭링크 생성 권한이 필요한 2개 건너뜀. 별도 reparse-point 모의 검사는 통과했다. 실제 구독을 호출하지 않는 자동 검사다.
- 실제 ChatGPT 구독 쓰기 시험: 47.06초, 작업 폴더의 CSS에 요청한 주석이 실제 저장되고 재조회로 확인됐다. 증거는 `test-results/development-write-probe/`에 있다. 초기 실패에서 도구 실행 호스트 및 Windows sandbox 설정 누락을 확인하여 명시적으로 연결했다. 전체 권한 실행이나 유료 API를 사용하지 않았다.
- 개발 통합 검사 9개: PM·R&D 허용, 다른 직원 거부, 대상 경로 정규화, 연결 불가 사전 중단, 담당 변경 제한, 변경 해시 고정, 서버 재시작 후 미리보기, 추가 지시 뒤 오래된 미리보기 분리.
- 작업 폴더·미리보기 검사 11개 중 10개 통과, 1개 위 Windows 조건으로 건너뜀. 소스 보존·변경 탐지·필수 DOM 유지·잘못된 JS 거부·경로 이탈 거부·미리보기 쓰기 차단 등을 검사했다.

## 검증 해석

### 실제 위임 미션과 화면 · 2026-09-30

- 기존 막힘 미션 `69a46efba98745aa88458e0a6920aaf1`에 현재 조직 화면 문맥과 대표의 디자인 방향을 전달하고 DAS-RD로 재배정했다. 성과 책임자는 DAS-PM이다. 자율 PM의 배정 판단을 구현한 것은 아니다.
- 실제 구독 실행 `8456edf62fac475aa03ed5775d7cec34`는 289.17초에 완료됐다. HTML·CSS 2개를 실제 수정했고, 기존 JavaScript와 필수 DOM 47개를 보존했다. 정적 검사·변경 해시를 확인한 미리보기는 `/previews/8456edf62fac475aa03ed5775d7cec34/`이다.
- 이 대화의 감독 에이전트가 브라우저에서 1440px·390px 및 기본 1280px 화면을 확인했다. 문서 가로 넘침 없음, 로고 로딩, 직원 선택·기억·성과 탭을 확인했다. 브라우저 오류·경고는 없었다. 임시 viewport를 해제했다. 직원 자체의 브라우저 도구 연결을 검증한 것은 아니므로 자동 delivery의 `browser_verified`는 false로 유지한다.
- 미리보기 안내띠가 로고를 가리는 문제와 20초마다 SSE가 종료되던 문제를 발견해 수정했다. 최종 화면에서 연결이 유지됨을 확인했다. 수정 후 개발 관련 자동 검사 20개 중 19개 통과, 위 Windows 조건으로 1개 건너뜀.
- 화면 증거: `test-results/office-design-preview-20260930.png`. 운영 디자인에는 적용하지 않았으며, 미리보기는 읽기 전용이다. 수정 권한 설정과 실행 연결은 운영 서버에 반영됐다.

- 가짜 Worker 검사는 배정·상태 전환·중지·저장·전달의 동작 검증이다. 실제 Codex 연결 성공이나 직원의 업무 품질을 검증하지 않는다.
- 실제 수행 결과의 형식 검증과 독립적인 목표 달성 검증은 다르다. 검증된 직원 성과를 단순 보고서 수로 대체하지 않는다.
- 음성은 사용자가 선택하는 입력 수단이다. 이 검증에서 실제 대표 음성·화자 인식·기기별 마이크 동작을 시험하지 않는다.
- 정기 업무 자동 실행, 자율 하위 에이전트 생성, 여러 공급자 동시 실행은 이번 최소 엔진의 작동 기능으로 보고하지 않는다.
