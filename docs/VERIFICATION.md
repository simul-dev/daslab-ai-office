# 2026-09-24 — 미션 컨트롤 개편 검증

출처: 새 로컬 웹을 지원 브라우저 도구(CUA)로 직접 확인한 기록, 임시 화면 검증 서버, AI를 호출하지 않는 회귀 테스트. 아래의 이전 v0.1 실제 실행 기록과 구분한다.

## 새 화면에서 확인한 내용

- 데스크톱에서 미션 요약 목록·달성 상태·달성률·소요 시간·난이도를 확인했다. 처음부터 보고서가 열리지 않으며 기본 화면에 `result.json`을 노출하지 않는다.
- 미션을 눌러 결과 보고서를 열고, 완료한 일·남은 일과 선택적으로 펼치는 전체 보고서를 확인했다.
- 필수 입력은 미션 한 칸이며 참고 자료는 선택 사항이다.
- 임시 작업자에 한 문장 미션을 제출해 실행 중 표시에서 약 20초 뒤 달성 보고로 바뀌는 동작을 확인했다.
- 달성한 미션의 선택적 수정 입력에 보완 내용을 적어 자동 재실행 후 다시 달성 보고가 되는 흐름을 확인했다.
- 보완 요청을 하나의 API로 처리하는 최종 흐름도 확인했다. 첫 미션을 수정해 즉시 실행한 뒤 다른 부분 달성 미션의 수정을 맡기면 대기열에 저장되고, 첫 실행이 끝난 뒤 자동으로 이어서 실행되어 약 20초 후 부분 달성 보고로 돌아왔다.
- 상태 필터와 너비 390px 모바일 화면을 확인했고 가로 넘침이 없었다.
- 위 화면 확인 동안 JavaScript 콘솔 오류가 없었다.

대기 요청이 실행으로 넘어간 뒤에도 이전 대기 안내가 남던 표시 오류를 수정했다. 현재 대기 상태인 미션에만 해당 안내를 표시한다. 마지막 표시 수정 후 JavaScript 구문 검사와 변경 내용의 공백 검사를 통과했다.

화면 검증에는 `tests/ui_fixture_server.py`를 사용했다. `127.0.0.1:8766`에 임시 데이터만 저장하고 달성·부분 달성·막힘 예시를 제공한다. 모든 예시는 `[화면 검증]`으로 표시하며 실제 AI 결과가 아니다. 운영 데이터 수정과 새 Codex 호출은 없었다.

`tests/browser_check.py`는 같은 화면을 사용자가 선택적으로 점검할 수 있도록 새 선택자로 갱신했다. 실제 작업자에 연결될 수 없도록 검증용 provider를 확인한다. 이 개편에서는 해당 Playwright 스크립트를 실행하지 않았으며 위 화면 확인은 CUA로 수행했다.

## 자동 검증 상태와 범위

`python -m unittest discover -s tests -v`: **85개 통과**(11.651초). 큐 복구·세부 산출물 달성률·의견을 보존하는 보완 요청 API를 포함한 최종 통합 결과다. `tests/browser_check.py`와 `tests/ui_fixture_server.py`의 Python 구문 검사도 통과했다.

새 테스트 범위는 한 문장 입력·자동 명세, 미연결 시 대기 보존, 자동 실행 대기열과 재시작·연결 복구, 승인 없는 달성 종료, 부분·미확인 결과 구분, 읽을 수 있는 이전 보고서, 실제 실행 시간 합산과 중단 회차 시간 미확인을 포함한다. 결과 계약은 세부 산출물의 근거·원문 기준 대응·달성률 일관성을 검사한다. 보완 요청은 다른 작업 실행 중이거나 일일 한도를 사용한 경우에도 의견과 대기 요청을 보존하며, 미션별 횟수 제한을 넘으면 자동 반복하지 않는지 확인했다. 검증 이후 보고서 파일이 변조되거나 삭제된 경우 자동 완료하지 않는 검사도 포함한다.

이번 확인은 인터페이스와 코드 동작에 대한 검증이다. 새 결과 계약으로 실제 AI를 실행한 품질, 외부 작업 수행, 실제 고객·사업 성과는 확인하지 않았다.

## 직접 읽어 확인한 산출물

첫 MVP는 **공사 견적 비교표 작성** 하나로 제안되었다. 대표의 배경 설명에 근거한 문제와 추가 확인이 필요한 가정을 분리했다. 입력 견적·공사 기준·근거 위치, 비교표·금액 점검·확인 사항, 실제 고객 업무 검증 계획과 완료 기준, 역할별 후속 작업이 포함되어 있다.

문서를 직접 읽어 정량 절감률·시장규모·고객 인터뷰 결과를 만들어내지 않았고, 고객 검증을 이미 수행했다고 주장하지 않았음을 확인했다. 이는 구현 담당의 문서 점검이며 **대표 승인이나 실제 고객 검증을 대체하지 않는다**. 업무는 `review`로 남아 있으며 `completed`로 바꾸지 않았다.

CLI 이벤트 중 Code Mode host를 끈 데 따른 도구 비활성 안내가 한 번 있었다. 실제 외부 도구 실행 없이 최종 구조화 응답과 완료 이벤트가 기록되었고 프로세스는 정상 종료했다. `stderr.log`는 비어 있다.
