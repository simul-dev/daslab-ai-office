# DAS Lab AI Office

짧게 미션을 맡기고, 달성 여부와 결과를 한눈에 받는 대표용 로컬 대시보드입니다.

최종 목표는 정기 업무를 수행하는 AI 직원과 중간 관리자가 있는 회사 시스템입니다. [대표의 회사 구상](knowledge/company-charter.md)과 [DAS Lab 팀·첫 업무 배정](knowledge/daslab-team.md)을 기준으로 발전시킵니다. 현재 웹은 초기 미션 실행기이며, 직원별 정기 실행·하위 위임·성과 누적은 아직 연결되지 않았습니다.

## 대표 전용 음성 비서 · 첫 시험 버전

[대표 전용 비서](http://127.0.0.1:8765/voice/)에서 **음성 엔진 준비 → 목소리 등록하기 → 로컬 듣기 시작** 순서로 사용합니다. “GPT야, 오늘 진행 중인 일 정리해줘”처럼 호출과 요청을 한 문장으로 말하세요. 목소리와 겹침을 기기에서 검사한 뒤 요청 초안을 보여 주며, **PM에게 맡기기**를 눌러야 텍스트가 기존 Codex로 전달됩니다. 주변 원음·음성 특징은 서버로 전송하지 않습니다.

첫 설치 또는 다른 PC에서 복원할 때:

```powershell
npm ci --ignore-scripts
python scripts/setup_voice_assets.py
python server.py
```

공개 모델·브라우저 런타임 약 104MB를 내려받아 로컬에서 제공합니다. 유료 음성 API·계정·토큰은 필요하지 않습니다. 실제 대표 목소리 정확도, 한국어 짧은 호출, 재생 공격 방어와 Fold4 실기는 미검증입니다. 현재는 열린 전경 브라우저용이며 잠금화면 상시 호출은 지원하지 않습니다. [구현과 시험 절차](docs/VOICE.md), [실제 검증 기록](docs/VOICE-VERIFICATION.md), [모델 선정 비교](docs/VOICE-MODEL-SELECTION.md)를 참고하세요.

## 사용하기

프로젝트 폴더의 PowerShell에서 실행합니다. Python 3.12 이상이면 별도 패키지가 필요 없습니다.

```powershell
python server.py
```

[로컬 대시보드](http://127.0.0.1:8765)를 열고 원하는 일을 평소 말하듯 적어 맡기세요. 참고 자료는 필요할 때만 추가합니다. 제목·사업 분류·우선순위·난이도·처리 순서·완료 기준은 내부에서 정리합니다. 현재 초기 분류는 코드 규칙으로 만들고, 실제 작업자가 내용을 다시 판단합니다.

미션을 맡기면 실제 Codex 실행을 시작하므로 계정 사용량이 발생합니다. 다른 미션을 실행 중이거나 연결·실행 제한 때문에 시작하지 못하면 미션과 이유를 대기열에 남깁니다. 시작 전인 미션은 실행할 수 있게 되면 우선순위에 따라 자동으로 이어서 처리합니다. 실패한 실행을 자동 반복하지는 않습니다.

대시보드에는 **달성 여부, 확인된 달성률, 실제 실행 시간, 결과 요약, 남은 일**을 먼저 보여 줍니다. 전체 보고서와 판단 근거는 필요할 때 펼쳐 봅니다. JSON과 실행 기록은 내부 기록용입니다.

완료한 일을 매번 승인할 필요는 없습니다. 원하는 결과가 아니면 보완할 내용을 짧게 적고 다시 맡길 수 있습니다. 이전 보고와 실행 기록은 보존합니다.

## 결과를 읽는 기준

- **달성**: 작업자가 미션 달성을 보고하고, 모든 완료 기준에 충족 근거가 있으며 기본 검증도 통과한 결과입니다.
- **부분 달성 / 막힘**: 끝낸 내용과 남은 이유를 함께 보고합니다. 보고서 생성과 미션 달성은 별개입니다.
- **달성률**: AI가 실제 요청한 결과를 세부 산출물로 나눈 경우, 그중 충족한 항목의 비율입니다. 세부 항목이 없으면 원래 완료 기준의 충족 비율을 사용합니다. 사실 구분·진행 보고 같은 내부 업무만으로 달성률을 올리지 않습니다. 항목은 동일 비중이며 작업량·시간·사업 성과의 비율은 아닙니다. 미확인 항목이 하나라도 있으면 수치를 표시하지 않습니다.
- **소요 시간**: 실행 시작·종료 기록을 기준으로 여러 실행의 시간을 합산합니다. 대기 시간은 제외하며, 실행 중인 회차는 현재까지의 경과 시간을 더합니다. 서버 중단으로 종료 시점을 알 수 없는 회차가 있으면 시간을 추정하지 않습니다.

기본 검증은 실행 성공, 응답 구조, 파일과 기준별 근거의 일관성을 확인합니다. 결과 내용의 진실성이나 실제 고객 검증까지 보증하지 않습니다. 이전 형식의 결과는 읽을 수 있는 요약을 제공하되, 새 판정 근거가 없으면 달성을 추정하지 않습니다.

## 현재 할 수 있는 일

제공한 미션과 자료를 바탕으로 **문서·분석·코드 제안**을 작성합니다. 작업자에게 외부 자료 검색, 다른 파일 탐색, 셸 실행, 추가 에이전트 호출 권한은 연결하지 않았습니다. 임의 저장소 수정, 프로그램 실행 검증, 외부 발송·구매·운영 배포도 수행하지 않습니다. 따라서 그런 실행까지 요구한 미션은 제안서만 만들어 놓고 달성으로 처리해서는 안 됩니다.

현재 PC의 Codex에서 ChatGPT 로그인이 확인된 경우에만 실행합니다. 인증이 필요하면 `codex login`으로 로그인하세요. 자동 탐지가 되지 않을 때는 `DAS_CODEX_PATH`에 설치된 `codex.exe` 경로를 지정할 수 있습니다. 인증 파일을 읽거나 복사하지 않고, API 키 결제로 전환하지 않습니다. 실제 비용과 잔여 할당량은 추정하지 않습니다.

동시 실행 1개, 미션당 3회, 한국 날짜 기준 하루 10회, 회당 600초가 기본 제한입니다. `config/office.json`에서 변경할 수 있습니다. 서버 중단 시 실행 중이던 미션은 실패로 복구하며 자동 재실행하지 않습니다.

## 저장과 검증

업무와 상태는 `data/office.sqlite3`, 실행별 입력·보고서·근거는 `data/runs/`에 저장합니다. Planner / Worker / Reviewer는 교체 가능한 인터페이스로 분리되어 있습니다.

이 웹은 127.0.0.1에서만 열리는 대표 1인용입니다. 현재 프로젝트가 OneDrive에 있으므로 동기화 중인 SQLite를 여러 PC에서 동시에 열지 마세요. 저장 위치를 바꾸려면 `python server.py --data-dir C:\DASLabOfficeData`를 사용합니다. 백업은 서비스를 종료한 뒤 데이터 폴더 전체를 복사합니다.

```powershell
python -m unittest discover -s tests -v
```

자동 테스트는 AI를 호출하지 않습니다. 화면만 확인하려면 `python tests/ui_fixture_server.py`로 임시 예시 서버를 열고 [검증용 화면](http://127.0.0.1:8766)을 사용합니다. 실제 AI와 운영 데이터는 사용하지 않습니다. 구조와 API는 [설계 문서](docs/PLAN.md), 새 화면과 이전 실제 실행의 확인 범위는 [검증 기록](docs/VERIFICATION.md)을 참고하세요.
