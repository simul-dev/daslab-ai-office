# 대표 전용 음성 비서 — 첫 구현

**2026-09-29 변경:** 음성은 조직 화면의 선택 입력이다. 버튼을 누른 동안에만 듣고, 호출어는 생략할 수 있다. 기존 화자·겹침 검사를 유지하며 명령 인식 후 마이크를 끈다. **조직 화면으로 가져오기**는 텍스트만 같은 탭의 입력창으로 옮기며 AI를 호출하지 않는다. 실제 지시는 조직 화면에서 맡기기 버튼을 눌러야 한다. 모든 기본 업무 제어는 UI로 가능하다. 아래 9월 24일 기록 중 PM 직접 전달·호출어 필수·조직도 미구현 설명은 이 변경과 [ORG-ENGINE.md](ORG-ENGINE.md)가 대체한다. 실제 개인 목소리·Fold4 검증 한계는 그대로다.

2026-09-24. URL: `http://127.0.0.1:8765/voice/`. 현재 PC의 Chrome에서 사용하는 첫 시제품이다. 기존 미션과 결과는 보존한다.

## 사용 방법

1. **음성 엔진 준비**를 누른다. 약 104MB의 설치된 공개 모델·런타임을 같은 로컬 서버에서 읽으며 마이크는 아직 켜지지 않는다.
2. **목소리 등록하기**를 누르고, 안내된 서로 다른 문장 3개를 각 8초 동안 대표 혼자 읽는다. 마이크 권한을 허용한다. 일관된 화자 특징과 단일 발화 품질이 확인돼야 등록한다. 원음은 저장하지 않고 특징 벡터만 해당 브라우저의 localStorage에 남긴다. 안내문을 실제로 읽었는지나 살아 있는 본인인지는 판정하지 않는다.
3. **로컬 듣기 시작**을 누르고 “GPT야, 오늘 진행 중인 일 정리해줘”처럼 말한다. 짧은 호출만으로는 화자 정보가 부족하거나 호출어가 오인식될 수 있으므로 처음에는 한 문장으로 시험한다. 12초보다 긴 말은 폐기한다.
4. 통과한 요청을 읽고 **PM에게 맡기기**를 누른다. 이때만 텍스트를 기존 미션 API로 보내고 Codex 실행·계정 사용량이 발생한다. 음성 특징·원음은 보내지 않는다. 전달 결과가 불명확하면 중복 실행을 피하기 위해 자동 재전송하지 않는다.

등록 삭제는 이 브라우저의 특징값만 지운다. 다른 브라우저·기기에는 등록 정보가 자동 공유되지 않는다. 목소리 등록은 화자 매칭용이며 신원·권한 인증이 아니다. 재생·합성음이 통과할 수 있다. 결제·계약·발송·배포 등의 고위험 실행은 음성만으로 승인하지 않으며 기존 Worker의 문서·분석 범위를 확대하지 않았다.

## 처리 경로와 개인정보

`마이크 → AudioWorklet → 16kHz 리샘플링 → 로컬 음성 구간 → pyannote 겹침/불확실/교대 검사 → 전체 명령을 덮는 3초 창별 WeSpeaker 화자 일치 검사 → 로컬 Whisper 한국어 전사 → 발화 앞 호출어 확인 → 초안 → 대표의 클릭 → 기존 PM/Worker`

- 원음은 짧은 메모리 버퍼에서만 처리하고 완료·거부·중단 시 버린다. 원음 업로드·서버 녹음 저장 API는 없다.
- 모델이 없는 상태·잘못된 입력·불확실한 화자·겹침·화자 교대·임계값 미달이면 기본적으로 넘기지 않는다. 일부 문장을 골라 이어 붙여 명령으로 만들지 않는다.
- 호출어만 통과하면 15초 동안 다음 명령을 기다리며, 다음 명령에도 같은 검사를 적용한다. 화자 불일치가 발생하면 대기 상태도 취소한다.
- 듣기 중 모델 처리에 시간이 걸리면 새 음성은 쌓지 않고 버린다. 사용자에게 처리 중임을 보여 준다.
- 탭 숨김·페이지 이탈·중단·등록 삭제 시 마이크를 끄고 처리 세대 번호를 변경해 늦게 도착한 결과가 되살아나지 않게 한다. 마이크 권한을 뒤늦게 허용한 경우도 트랙을 중지한다.
- 음성 모델 Worker는 원격 모델을 허용하지 않고 동일 출처의 정적 자산 GET/HEAD만 허용한다. 음성 페이지 CSP도 외부 연결을 막는다. 로컬 서버는 계속 loopback에만 바인딩한다.
- 음성 응답은 브라우저가 `localService`로 보고하는 한국어 TTS 음성이 있을 때만 사용한다. 없으면 화면에만 응답하며 네트워크 TTS로 전환하지 않는다.
- 첫 등록 임계값은 세 표본의 최소 쌍별 일치도에서 내부 여유를 뺀 보수적 초기 정책이다. 정확도·타인 수락률로 해석하지 않는다. 별도 실제 화자 평가 전 보안용으로 사용하지 않는다.

## 실제 구현 범위

대표 → 전용 비서 → PM → 전문 리드의 역할 경계를 화면에 표시한다. 비서는 기존 미션의 달성·진행·막힘을 요약하고 확인된 요청 초안을 기존 `/api/missions`에 전달한다. 이번 화면의 조직 경로는 책임 관계 설명이며 클릭 가능한 실제 조직도나 직원 실행 상태 표시가 아니다.

현재 전달 범위는 DAS Lab `project_id=daslab`이다. 특정 PM 프로세스/세션 ID에 명령을 고정하지 않았지만 **여러 PM의 독립 실행·라우팅·우선순위 조정·상호 위임·직원별 대화·성과 누적은 구현하지 않았다.** 기존 코드 Planner와 단일 Worker를 사용한다. 음성 입력 UI를 실제 비서 LLM의 독립 상주 실행이나 회사 조직 완성으로 보고해서는 안 된다.

## Fold4 범위

이 PC의 `127.0.0.1`은 휴대전화의 주소가 아니다. LAN에 공개하거나 인증 없는 외부 접근을 열지 않았다. Fold4에 연결하려면 인증·HTTPS 제공과 실기 시험이 별도로 필요하다. 전경 웹의 동작 가능성과 현재 연결 완료를 구분한다.

브라우저에서는 화면을 켜고 페이지를 보고 있는 동안만 듣는다. 화면 잠금·다른 앱 전환을 감지하면 중지한다. 잠금 화면에서 안정적인 호출은 Android microphone foreground service 등 네이티브 구현이 필요한 별도 범위다. 모델 크기만 보고 Fold4의 메모리·지연·배터리 성능을 추정하지 않는다.

## 유지보수와 검사

```powershell
npm ci --ignore-scripts
python scripts/setup_voice_assets.py
python scripts/setup_voice_assets.py --check
node --test tests/voice_policy.test.mjs
python -m unittest discover -s tests -q
```

모델과 런타임은 `config/voice-assets.json`의 고정 버전·크기·SHA256을 검사한다. 32개 자산 총 103,584,791 bytes. 다운로드 실패 시 이전 파일을 보존하고 ready=false를 남긴다. Git에는 대형 자산을 넣지 않으며 설치 스크립트로 복구한다. 코드와 모델별 라이선스는 [VOICE-ENGINES.md](VOICE-ENGINES.md)에 구분한다.

공개 예제로 실제 엔진만 검사하려면 `python scripts/setup_voice_test_samples.py` 후 `/voice/diagnostics.html`을 사용한다. 대표의 등록을 변경하지 않고 마이크를 사용하지 않는다. 개발용 공개 음성은 해당 예제 출처만 기록하고 배포물에 포함하지 않는다. 결과는 사람의 실제 신원 인증·한국어·Fold4 정확도를 뜻하지 않는다.

## 남은 사용자 시험

대표가 세 문장을 등록한 뒤 자신의 정상 명령, 다른 사람의 같은 호출과 명령, 대표 호출 후 타인 명령, 동시에 말하기를 확인해야 한다. 소음·거리·다른 날의 음성·녹음 재생도 별도 시험한다. 등록·임계값 조정용 샘플과 최종 평가용 샘플을 분리하고, 타인 수락/본인 거절/호출 누락/명령 오류/지연을 각각 기록한다. 현재 실제 사용자 자료 없이 이러한 성능 수치를 만들지 않았다.
