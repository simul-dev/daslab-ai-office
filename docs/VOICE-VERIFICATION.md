# 음성 비서 검증 기록

2026-09-24. 자동 시험은 임시 데이터·공개 샘플만 사용했다. 대표의 마이크 녹음·음성 등록·실제 AI 실행·외부 발송·유료 결제는 수행하지 않았다.

## 실제 브라우저 추론

임시 fixture 서버 `http://127.0.0.1:8766`에서 내장 Chromium으로 실행했다. 기존 실제8765 데이터와 분리했고 UI fixture는 실제 AI를 호출하지 않는다.

- 실제 로컬 모델 초기화 성공: WeSpeaker q8, pyannote fp32, Whisper encoder fp32/decoder q8.
- Hugging Face 공식 Transformers.js 화자 예제 4개를 사용했다. 같은 화자 2쌍 cosine은 **0.7362275 / 0.7589756**, 다른 화자 4쌍은 **0.1515240 / 0.0678495 / 0.1329233 / 0.0535868**이었다. 이 작은 샘플에서 분리된다는 뜻이며 타인 수락률 또는 실제 대표 판정 정확도가 아니다.
- 네 단일 화자 샘플은 모두 speakerCount=1, overlapSeconds=0으로 반환됐고 초기 발화 품질 정책을 통과했다.
- 서로 다른 두 화자 샘플을 동일 길이로 합성 혼합한 입력은 overlapMax=**0.9980427**, overlapSeconds=**2.9205710**, 단일 화자 수=0으로 반환돼 정책에서 거부했다. 실제 현장 겹침·마이크·반향 시험은 아니다.
- Whisper를 한국어 인식 설정으로 실행했으나 공개 시험 파일 자체는 영어다. 실제 출력은 “The bogus legislature numbered 36 members.”였다. 전사 엔진이 동작하는지 확인한 것이며 한국어 호출어 검증이 아니다.
- 위 실제 공개 샘플 검사 전체는 해당 데스크톱 실행에서 **7.5초**였다. 캐시·장치·입력 길이에 영향을 받으며 사용자 단일 명령 지연이나 Fold4 성능으로 해석하지 않는다.

출처: [공개 화자 예제](https://huggingface.co/Xenova/wavlm-base-plus-sv), dataset revision `fbe92bd97d48f3ec17779d8d8f2964e1c6bc7634`. 개발용 WAV 4개는 별도 스크립트에서 SHA256을 검사하고 Git에서 제외한다. 임의 합성 판정값을 실제 모델 결과로 사용하지 않았다.

## 코드·서버·화면 확인

| 확인 | 결과 |
| --- | --- |
| Python 전체 회귀 | 96개 실행, 95개 통과, Windows 심볼릭링크 생성권한이 필요한 1개 건너뜀 |
| JS 음성 정책 | 16개 통과: 등록·손상 프로필·무음·clipping·겹침·화자교대·창별 불일치·호출어 위치·만료·리셋·긴 음성·늦은 마이크 허용 취소 등 |
| 자산 | 32개 전체 크기·SHA256 검증 통과, 103,584,791 bytes |
| HTTP | 음성 경로 격리, 경로 이탈/숨김/디렉터리 차단, 모델 스트리밍, 기존 Host/Origin 보호, 오디오 POST 미지원 |
| UI | 모델 준비 버튼의 실제 초기화 성공, 등록 전 듣기 비활성, 미션 실제 fixture 상태 요약, 기본 화면 JS 경고/오류 없음 |
| 반응형 | 360px 너비에서 문서 너비 345px로 수평 넘침 없음. 실제 Fold4 시험은 아님 |
| 기존 서버 반영 | 실행·대기 미션이 없는 것을 확인한 뒤8765 서버 재시작. `/voice/` HTTP200, 기존 미션1개와ID 보존, 서버오류로그 비어 있음 |
| 사용자에게 표시 | Windows에서 Chrome으로 `/voice/`를 열고 실제 프로세스 창 제목 `DAS Lab · 대표 전용 비서 - Chrome` 확인. Chrome 내부 자동제어 연결은 없어 내부 추론 검증은 위 임시Chromium에서 수행 |

정책 테스트의 합성 벡터·PCM은 제어 논리 검증용이다. 실제 모델 정확도 결과와 혼동하지 않는다. Worker는 동일 출처의 로컬 자산 읽기만 허용하고, 앱의 쓰기 요청은 대표가 누르는 `/api/missions`의 텍스트 전달뿐임을 코드 검토했다. 실제 대표의 라이브 마이크 세션 전체를 네트워크 계측한 시험은 아직 아니다.

## 아직 확인하지 않은 범위

대표의 실제 등록 성공·다른 사람의 오수락/본인 거절률, 한국어 “GPT야”·명령 정확도, 실제 여러 사람/TV/소음·재생·합성 공격, 긴 시간 사용, Fold4의 지연·메모리·발열·배터리·잠금화면, 실제 Codex에 음성 명령을 전달한 뒤의 종단 업무 실행은 미검증이다. 대표가 등록·시험할 수 있는 지점까지 구현했으며, 이 결과를 배포 가능한 보안 인증이나 상시 모바일 비서 완성으로 보고하지 않는다.
