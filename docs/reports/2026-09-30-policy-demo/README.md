실행 시간은 직원 작업 기록이며 전체 개발·감독·오류 수정 시간과 다르다. 원문 파일은 직원 보고서를 그대로 복사했다. 원문에 ‘소요 시간 미집계’라고 적힌 부분은 직원이 작성 당시 실행기의 측정값을 받지 못했기 때문이며, 위 시간은 실행 기록 기준이다.

R&D 실행 뒤 정적 검사기가 테스트용 Node 기본 모듈을 외부 코드로 잘못 분류했다. 검사기를 좁게 수정하고 원본 실패·보고·소스를 보존한 채 같은 파일을 재검사했다. 독립 브라우저 32항목이 통과했고 원시 기록에서 비용·납기·재고 보존을 재계산했다. 사용자 브라우저에서도 긴급용량 0, 기준 복원, 가정 표시를 확인했다. 자세한 범위는 [모델 계약과 실제 검증](../../SUPPLY-CHAIN-POLICY-DEMO.md)을 따른다.

PM은 현장 효과가 검증됐다고 판정하지 않았다. 합성 조건에서 P0/P1/P2를 비교하는 내부 설명용 데모다. SNS 게시, 영상 제작, 고객 접촉, 현장 데이터 검증, 3D·실시간 연동과 공개 배포는 미완료다. `marketing.md`의 2주 일정은 미예약 계획이다.

다음 내부 우선순위는 실제 지연 인지 시점·긴급 운송 실패·용량·비용 항목을 고객 데이터로 바꿀 때 필요한 모델 수정 범위다. 외부 실행은 계정·대상·권한이 연결된 구체적 단계에서 진행한다.
