# 공급 지연 대응 파일럿 제안

공급이 늦어질 때, 재고를 더 보유할지 기존 발주 일부를 긴급 운송으로 전환할지 판단할 근거를 제공합니다. DAS Lab은 제조·유통의 SCM·수급계획·자재관리 조직을 대상으로, 동일한 수요·공급 지연 조건에서 납기 충족과 비용을 비교하는 이산사건 시뮬레이션(DES) 파일럿을 제안합니다.

단일품목 합성 데모는 14일·하루 6주문·총 84주문, 초기재고 12, seed 42, 안전재고 2일, 긴급용량 6 조건입니다. 기본재고 P0의 OTIF는 53.57%, 총비용은 115.74 CU입니다. 안전재고 확대 P1은 94.05%·133.58 CU, 기존 발주 일부 긴급전환 P2는 94.05%·267.69 CU입니다. OTIF는 납기 내 전량 충족률, CU는 가상비용 단위입니다. 실제 고객 효과나 원화 견적이 아니며, P1의 일반적 우위나 개선을 보장하지 않습니다.

데모는 발주 시 지연을 미리 알고 긴급편은 지연되지 않는다고 가정합니다. 처리용량은 무제한이고 구매원가·품절벌금은 제외했습니다. 고객 데이터 적용·현장검증·공개 배포는 미완료이며, 3D는 없고 실시간 연동도 검증되지 않았습니다.

파일럿은 한 거점·한 품목의 과거 운영을 재현하고 현행 정책과 대안을 비교합니다. 실제 지연 인지 시점, 긴급 운송의 지연·용량, 비용 범위를 먼저 확인합니다. 산출물은 데이터 품질·가정 목록, 현행 재현 결과, 정책별 서비스·비용 비교표, 민감도 분석과 적용·보류 조건입니다. 성공 기준을 사전 합의하고 데이터 부족이나 기준 미충족 시 적용을 보류합니다. 기간·가격은 데이터와 모델 수정 범위를 확인한 뒤 협의합니다.
