# 회사 구상과 대표의 운영 원칙

2026-09-29 후속 지시: 조직 운영 엔진과 시각적 조직도를 중심으로 개발하고, 직원별 기억·배정·상태·성과와 대표의 지시·개입을 연결한다. UI로 직접 제어하는 것이 기본이며 음성은 버튼으로 선택하는 입력이다. 초기 구현의 실제 범위와 한계는 [조직 엔진](../docs/ORG-ENGINE.md)을 우선 참조한다. 아래 요구사항 기록은 유지한다.

기록일: 2026-09-24 (Asia/Seoul). 출처: 대표의 현재 직접 지시와 기존 「멀티에이전트 회사 시스템 구축」 대화. 현재 직접 지시가 이전 예시·제안보다 우선한다.

## 목표

대표가 최종 supervisor를 맡고, 사업별 프로젝트 관리자 아래 여러 AI 직원이 매일·매주 정해진 업무를 주도적으로 수행하는 회사 시스템을 만든다. 직원은 업무 목표를 이해하고 간단한 일은 직접 수행하며, 복잡한 일에는 필요한 전문 subagent를 만들어 분담·진척·검증·통합을 책임진다. 대화하는 캐릭터나 작업창 여러 개를 만드는 것만으로 이 목표를 달성한 것으로 보지 않는다.

직원별 역할·지시·도구·상시 업무·업무 이력·프로젝트 지식은 개별 채팅이나 특정 계정에만 갇히지 않도록 보존한다. 실행 세션이 바뀌어도 직원의 책임과 기억이 이어져야 한다. 자연어 호출이나 에이전트 간 회의는 이 업무 구조를 지원하는 수단이다.

## 대표의 부담을 줄이는 방식

- 대표는 평소 말하듯 미션과 방향을 준다. 업무목표·입력자료·완료기준·근거를 일일이 양식으로 작성하거나 검토할 의무가 없다.
- PM과 담당 직원이 맥락·우선순위·난이도·처리 절차·배정·완료 기준을 내부 판단한다. 기존 자료에서 답을 찾고 사소한 선택은 스스로 한다.
- 요약 보고에는 담당자와 역할, 달성 여부, 실제 결과, 소요 시간, 부분 달성 시 완료 범위와 남은 이유를 보여 준다. 근거가 있는 경우에만 달성률을 표시한다.
- 세부 계획·검증 자료·실행 기록은 필요할 때만 펼쳐 본다. JSON은 내부 저장 형식이다.
- 비용·중요한 대외 약속·상충하는 사업 방향처럼 대표의 판단이 실제 필요한 사안만 간결하게 올린다. 반복 승인이나 직원의 자기관리 업무를 대표에게 떠넘기지 않는다.

## 사업 우선순위

**현재 1순위는 DAS Lab이다.** 컨설팅·시뮬레이션·디지털트윈·AI 서비스의 경쟁력을 높이고 사업모델을 확장한다. 시뮬레이션 연구개발, 기획마케팅, 영업지원 직원을 먼저 구성한다. 현재 첫 미션과 조직은 [DAS Lab 팀과 업무 배정](daslab-team.md)에 기록한다.

아래는 보존할 후속 사업 구상이다. 순서가 확정된 실행 계획이나 가동 중인 팀을 뜻하지 않는다.

1. **프랜차이즈·출점 지원:** 테스트 중인 영업용 솔루션 MVP를 발전시킨다. 도면 외주·수정, 철거·전기·배관·목공 업체 탐색, 견적·단가 비교, 턴키/분리발주, 공정 일정, 현장 점검, 소방 기준 확인, 작업자 간 조율, 개점과 기존 점주 이슈를 줄이는 기회를 찾는다. 이는 대표가 전한 동생의 현장 pain point이며 시장 전체의 정량 검증은 아직 아니다.
2. **도면·제품·견적 연결:** floor plan의 2D/3D 구성품, 공사 자재, 식당 설비·제품을 식별하고 가격·판매율 등 선택 기준별 순위를 제공한다. 제품·자재·투입 인력과 인건비를 바탕으로 분리발주/턴키 견적을 비교하는 시스템을 검토한다.
3. **사업기회 발굴:** 현장 pain point에서 업무를 줄일 비즈니스 기회를 찾고, 근거와 우선순위를 보고하며 MVP와 실제 테스트를 제안한다.
4. **리스크 서비스:** 바이브코딩 취약점을 포함한 보안·지적재산권·금융범죄 노출·세금·소송 관련 리스크를 분석·보고하는 무료 서비스와 고위험 영역의 정기 개선 서비스를 검토한다. 분석 초안과 실제 전문가 검토·개선 완료는 구별한다.
5. **동기부여 미디어:** AI 시대의 태도·동기부여 Instagram을 운영하는 인플루언서 에이전트.
6. **AI 연예기획사:** SNS AI 연예인들을 관리하는 대표 에이전트와 직원 조직.

## 보존 상태

### 후속 지시: 대표 전용 비서

대표 바로 아래에 전용 비서를 둔다. **대표 → 대표 전용 비서 → 사업·프로젝트별 PM들 → 전문 리드 → 필요한 하위 에이전트**가 확장 방향이다. 비서는 대표의 자연어 요청을 정리하고 전체 우선순위와 결과를 통합 보고한다. PM은 세부 실행계획·업무 배정·성과 검수를 책임진다. PM마다 전문 인력을 전용으로 둘지 공유할지는 미확정이다. 여러 PM 실행·조직도에서 직원 클릭 대화·직원별 실시간 업무와 성과 추적은 요구사항이며 아직 가동 기능이 아니다.

대표는 Galaxy Z Fold4를 사용하며, 주변 사람의 말에 반응하지 않고 등록한 목소리의 호출과 명령을 받는 전용 비서 시제품 개발을 요청했다. 전체 주변 대화를 서버로 보내는 상시 음성 서비스는 원하지 않는다. 원음은 기기 내에서 처리하고, 호출 뒤 명령의 화자도 다시 검사한다. 이번 브라우저 첫 구현은 [VOICE.md](../docs/VOICE.md)에 기록한다. 음성 일치는 대표 권한의 자동 상속이나 결제·계약 등의 승인 수단이 아니다.

아침의 원문 대화는 확인했다. 이번 기록 이전에는 `knowledge/projects.json`의 DAS Lab 지식이 비어 있었고, 위 조직 구상 전체를 보존한 프로젝트 문서가 없었다. 확인한 Codex 로컬 메모리 DB에서도 DAS Lab 관련 추출 항목을 찾지 못했다. 이는 ChatGPT 계정 메모리 전체를 확인했다는 뜻은 아니다.

이 문서와 루트 `AGENTS.md`를 앞으로의 프로젝트 작업에서 읽도록 연결했다. 글로벌 메모리 DB를 직접 수정하지 않았다. 대시보드 실행기는 별도이며, 이 문서를 저장한 것만으로 직원 스케줄·도구·실행 이력이 자동 연결되는 것은 아니다.
